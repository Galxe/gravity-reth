# Gamma runtime bytecodes

These files are exact binary decodings of the runtime artifacts generated by
`gravity_chain_core_contracts` commit
`3bbc0b71bbccbeec89c706312fb2636723b594fa`.

| Contract | Size | Keccak-256 |
| --- | ---: | --- |
| `NativeOracle` | 3904 bytes | `0x981087ccdaa0b7843960782e99b078ccdd3820b331f86ce337d9750c5565d984` |
| `OracleTaskConfig` | 4662 bytes | `0xa21bf93e6123b0104b9ea851b8154fb342a5b576c22c71f15f851e266faa9f7f` |

`NativeOracle.pre.hex` is a test-only, hex-encoded copy of the 4602-byte
pre-fork runtime from the production testnet/mainnet genesis. Its Keccak-256 is
`0x30dd3888ce26735c0d6c5a036b48a1de668dd5506efa7588ce450f976da28255`.
The activation-boundary regression test executes a real legacy `recordBatch`
against this runtime before installing the post-fork bytecode.

The Grevm post-execution migration validates both current testnet codehashes
before applying one shared `EvmState` through
`ParallelExecutor::apply_state_change`. The activation block commits the new
runtime in its final state; transactions begin observing the new runtime in the
following block. Both normal parallel execution and `disable-grevm` sequential
execution use `GrevmExecutor` and therefore share this transition.
